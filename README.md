# CODE

A minimalist cryptogram game. Decode English quotes by finding the letter behind each number: the same number always means the same letter.

Play 16 offline puzzles across three difficulty levels, with starting clues, optional hints, undo and saved progress. Light and dark themes, designed for comfortable play on your phone.

No ads, accounts, subscriptions or paid features.

## Made with

- TypeScript
- HTML
- SCSS
- Vue 3
- Vite
