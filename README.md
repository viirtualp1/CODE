# CODE

A minimalist cryptogram game. Decode English and Russian quotes by finding the letter behind each number: the same number always means the same letter.

Play 200 offline puzzles — 100 in each language — across three difficulty levels, with starting clues, optional hints, undo and saved progress. Keep a backup file and enjoy each quote in full after solving it. Continue from a quiet home screen, try a short practice puzzle, and choose System, Dark or Light appearance for comfortable play on your phone.

No ads, accounts, subscriptions or paid features.

## Made with

- TypeScript
- HTML
- SCSS
- Vue 3
- Vite
